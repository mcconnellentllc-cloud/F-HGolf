Rental Carts

The course's physical fleet + the members who lend a cart when the club rentals run out. Every tournament pulls from this list; edit here, not on the tournament workbook. Each cart card holds the shed / spot / power / special instructions so the pro shop can find it fast.

Member cart pool — folks who've offered to lend their cart once the on-site rentals run out. The Check-In cart-assignment dropdown on every tournament will list these entries after the rental threshold is hit.
